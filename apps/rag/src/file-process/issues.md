# 文件处理服务问题

## 已识别的潜在问题

1. **文件清理机制缺失**
   - 处理后没有自动清理上传文件
   - 文件在 `./src/files` 目录中随时间积累
   - 没有在文件不再需要时删除它们的机制

2. **错误处理不一致**
   - 某些错误可能被转换为通用的 `InternalServerErrorException`
   - 错误消息可能不提供足够的调试信息
   - 缺少针对不同失败场景的特定错误类型

3. **文件路径验证**
   - 对从元数据服务接收的文件路径验证有限
   - 如果文件路径被操纵可能存在安全风险
   - 没有检查路径遍历漏洞

4. **资源管理**
   - 处理失败时没有显式的资源清理
   - 大文件可能导致内存使用增加
   - 没有对长时间运行的文件操作进行超时处理

5. **策略工厂限制**
   - 目前仅支持 PDF 文件
   - 工厂中硬编码的策略映射
   - 没有动态策略注册机制
