# Reverse Roadmap 本地开发指南

## 前置要求

- Node.js >= 20
- Docker 与 Docker Compose
- 一个 DeepSeek 账号（用于申请 API Key，见步骤 2）

## 1. 克隆仓库

```bash
git clone https://github.com/bignosecss/reverse-roadmap.git
cd reverse-roadmap
```

## 2. 申请 DeepSeek API Key

RAG 服务依赖 DeepSeek 大模型，需要先拿到 API Key：

1. 打开 DeepSeek 开放平台：https://platform.deepseek.com/
2. 注册 / 登录账号
3. 进入「API Keys」页面，点击「Create new secret key」
4. 复制生成的 Key（关闭弹窗后无法再次查看，请妥善保存）

## 3. 配置环境变量

在项目根目录创建 `.env` 文件：

```bash
ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin123
DEEPSEEK_API_KEY=步骤2申请到的Key
```

## 4. 启动服务

```bash
docker compose build && docker compose up -d
```

首次启动会下载镜像、拉取 Ollama 嵌入模型，耗时较长，请耐心等待。

## 5. 访问应用

| 服务 | 地址 |
| --- | --- |
| 前端（Web） | http://localhost:3000 |
| 后端 API | http://localhost:3001/api/ |
| RAG 服务 | http://localhost:3002/rag/ |

打开前端地址，使用 `.env` 中配置的 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 登录即可。

## 常用命令

```bash
docker compose ps          # 查看服务状态
docker compose logs -f     # 查看实时日志
docker compose down        # 停止并删除容器
```
